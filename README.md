# Comms skills

Skills that help communications and PR people get more from Claude. Each skill is a folder with a `SKILL.md` file that tells Claude how to do one job well.

These skills come from [MVPR](https://mvpr.io/r/kJwA7pjNhrI).

## Skills

| Skill | What it does |
|---|---|
| [`claude-code-onboarding`](skills/claude-code-onboarding) | A kind, step-by-step guide for people who have never used a terminal. It takes you from nothing to a live website: install Claude Code, learn plan mode and accept edits, design on an editable board, build with Astro, publish on Vercel. It ends with 2 projects: an editable report or deck (HTML, PDF and PowerPoint) and a database for large coverage, social and GEO data. |

## Start here if you are new (no technical skills needed)

1. Download the starter ZIP: [Claude-Code-Starter.zip](https://github.com/tom-lawrence-mvpr/comms-skills/raw/main/downloads/Claude-Code-Starter.zip). Keep it in your Downloads folder.
2. Open Claude at https://claude.ai, or get the app at https://claude.ai/download.
3. Start a new chat. Drag the ZIP into the message box.
4. Type: `Please read this and guide me through getting started. Go one step at a time.`

Claude does the rest. If your chat cannot open a ZIP, unzip it and drag in the file `START-HERE.md` instead.

## Install a skill in Claude Code (if you already use it)

Ask Claude Code: `Copy the folder skills/claude-code-onboarding from this repo into ~/.claude/skills/`. Then type `/claude-code-onboarding`.

## Status

- Tested on a Mac, from the install step to the Vercel sign-up, and in a browser for the design board and the report deck.
- Not tested yet: Windows, the live Vercel deploy, and the PowerPoint file in real PowerPoint.
- The guide is written to be kind and slow. If a step confuses you, tell Claude. It will explain it again.
